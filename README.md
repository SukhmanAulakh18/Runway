# Runway 🍊

**Sheridan Datathon 2026 · Tangerine track ("Resilience Rewired")**

Runway is a tool a bank advisor uses to answer one question: **if something goes wrong for this customer, how long can they last, and what should they do about it?**

Pick any customer, see their money picture, hit them with a shock (job loss, higher bills, a surprise repair), and get a plan. Underneath, it finds customers who look fine on average but keep dipping close to $0. Those customers are far more likely to go overdrawn, and in this bank's data every borrower who went overdrawn defaulted on their loan.

## What we're building (plain English)

The app has five tabs:

| Tab | What it shows |
|---|---|
| **Watchlist** | Customers ranked by how close their balance gets to zero, with a plain reason for each. A **Time Machine** rewinds to Dec 2023 or Dec 2024 and reveals who really went overdrawn next. A **bank view** shows how many of all customers would still have money each month after a shock. |
| **1 · Know the customer** | Their money in, money out, savings, the judges' runway number, our more realistic number, a warning score, and their loan if they have one. |
| **2 · Take a shock** | Type the judge's twist card ("laid off, EI 55% for 6 months, bills up 15%"); the app reads it and recalculates. Shows both runway numbers, why they differ, and the chance the customer makes it 6 months. |
| **3 · Make a plan** | An emergency-fund goal with dates, a backup plan if the shock hits, and the smallest monthly cut that keeps them out of overdraft. |
| **Why trust it** | Every finding with its evidence and its limits. |

## Quick start (10 minutes)

```bash
# 1. Get the code
git clone <your-repo-url> runway && cd runway

# 2. Python environment (Python 3.11+)
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 3. Data: put the Tangerine CSVs in ./data   (never commit this folder)
#    data/monthly_summary.csv, data/loans.csv, data/clients.csv, data/dispositions.csv, ...
#    or point to them:  export RUNWAY_DATA=/path/to/Tangerine/data

# 4. Check everything works
python scripts/check_setup.py   # tells you exactly what's wrong, if anything
python scripts/audit_data.py    # data integrity checks → docs/DATA_AUDIT.md
pytest -q              # engine tests, ~5 seconds; expect "34 passed"
pytest -q -m ui        # app smoke test, ~10-60 seconds; expect "6 passed"

# 5. Run the app
streamlit run app.py   # opens http://localhost:8501
```

**Optional AI (Google Gemini):** the app works without it, using built-in rules. To turn it on with the event's Google Cloud credits:
1. Enable the Vertex AI API.
2. Run `gcloud auth application-default login`.
3. Run `export GOOGLE_CLOUD_PROJECT=your-project-id`.

Or use `export GEMINI_API_KEY=...`. The sidebar shows which AI is active.

## The four rules

1. **Pages never compute money.** If a page needs a new number, add a function to `engine.py`, add a test, then call it.
2. **Never commit `data/`, `.env` or keys.**
3. **Tests must pass before you open a pull request:** run `pytest -q`, and also `pytest -q -m ui` if you touched `app.py` or `ui/`.
4. **Stay in your files** (see `docs/TASKS.md`). If you need to change someone else's file, tell them first.

## Commands

| Command | What it does |
|---|---|
| `python scripts/check_setup.py` | Setup doctor (run first if anything fails) |
| `python scripts/audit_data.py` | Data checks, regenerates docs/DATA_AUDIT.md |
| `pytest -q` | Engine tests (fast) |
| `pytest -q -m ui` | Clicks through the whole app headless |
| `pytest -q -m slow` | Re-checks the statistical evidence (1–2 min) |
| `python evidence.py` | Rebuilds `evidence.json` from the raw data |

## Data and sources

- PKDD'99 Discovery Challenge Financial dataset (real anonymized 1990s Czech bank data, re-dated to 2020–2025 and converted to CAD by the organisers): https://relational.fel.cvut.cz/dataset/Financial
- Government of Canada, EI regular benefits (55%, maximum $729/week in 2026): https://www.canada.ca/en/services/benefits/ei/ei-regular-benefit/benefit-amount.html
- Built with Python, pandas, NumPy, SciPy, scikit-learn, Streamlit, Plotly, and Google Gemini (Vertex AI).
